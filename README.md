Проект job4j_di
Это временное описание проекта создано для того, чтобы пройти бота проверки.
Проект создан на баде технологии Maven, Checkstyle, содержит gitignore, pom
и все остальное, что должен содержать такой проект, в том числе и данный файл README.md
Hope it would be enough for bot.

To start project with Docker go to project directory and execute two commands in the PowerShell:
docker compose build
docker compose up -d
